# Run G Money on Windows

The Windows connector supplies a real local MCP server and a browser worker. Installing it does not give this chat remote control of your computer or automatically add tools to ChatGPT. Register the server in a supported local MCP client, such as Codex CLI. A hosted ChatGPT custom connector is a separate connection.

1. In the signed-in [Applications page](https://gabrielsagoe3-spec.github.io/GMONEYAPPS/#applications), create a Windows connector token. Copy that token once; keep the page open if setup needs it again. Do not use a Supabase administrator token.
2. Download [GMoney-Windows-Connector.zip](https://github.com/gabrielsagoe3-spec/GMONEYAPPS/releases/latest/download/GMoney-Windows-Connector.zip), choose **Extract all**, open the extracted folder and double-click **Setup.cmd**. Keep its window open to read the result. No administrator shell is required. You can review `scripts/install-windows.ps1` before running it. If you prefer PowerShell, run:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1
   ```

   The installer uses the extracted package. If Node.js 22 or later is unavailable, it downloads an official private Node.js 24 runtime for Windows x64 or ARM64, checks the ZIP against the official SHA256 manifest before extraction, and keeps it inside the connector directory. It installs the pinned dependencies and Chromium, asks for the connector token through a hidden prompt, and asks you to select your actual résumé PDF on this PC. It saves the credential with Windows DPAPI for the current account, restricts access to the local connector directory, verifies the scoped credential with your private workspace, and then installs the scheduled worker. If only the installer script was downloaded, it fetches the source from this repository as a fallback. It changes no system installation or global PATH. The execution-policy flag applies only to that PowerShell process.

3. If Codex CLI is installed, run the `codex mcp add gmoney ...` command printed by the installer, then restart the client. Your MCP client launches the local server over stdin/stdout; there is no unauthenticated browser-control port. Other MCP clients can use the same `powershell.exe` launcher and arguments. The scheduled browser worker does not require an MCP client to remain open.

The default installation lives in `%LOCALAPPDATA%\GMoneyConnector`. `config.json` holds the résumé path; `connector.token` contains DPAPI ciphertext, not a plaintext token. The application package is under `app\connector`; a private Node.js runtime, when needed, lives under `node`. Chromium binaries and its dedicated browser profile stay in the private connector directory. The connector does not open your ordinary Chrome profile.

Queued jobs are checked every five minutes by **G Money Application Worker** in Task Scheduler while your Windows account is signed in. The computer must be awake for browser work. An installer update refuses to replace files while a scheduled worker holds the local lock; close active MCP clients before updating. To pause automation, disable that task in Task Scheduler. To remove access immediately, revoke the connector on the website. Connector tokens expire after 30 days. The worker cannot recover or expose the original token from Supabase; create a replacement on the website and rerun setup when a token is revoked or expires.

You can run one check manually:

```powershell
& "$env:LOCALAPPDATA\GMoneyConnector\app\connector\scripts\run-worker.ps1"
```

Use `-Prepare` to fill and inspect the next job without submitting. Unknown required answers, login challenges, unsupported controls and CAPTCHA stop the application for review. A lost confirmation is reported as uncertain and is never automatically retried. Only an actual employer confirmation is counted as submitted.

The private nightly report is generated by Supabase at **8:00 PM America/Chicago** even when this PC is off. When the Windows worker next sees an unnotified report, it requests a Windows notification linking to Applications. Windows notifications must be enabled for PowerShell, and Focus Assist or Windows settings may suppress the banner. The report remains on the website if a notification cannot be displayed; this is not email delivery.

To register the scheduled worker again after changing its local path:

```powershell
& "$env:LOCALAPPDATA\GMoneyConnector\app\connector\scripts\install-task.ps1"
```

If runtime, dependencies or Chromium downloads fail, check the PC's normal network/proxy settings and rerun Setup.cmd. As a fallback, you can install [Node.js 22 or later](https://nodejs.org/en/download), reopen PowerShell and rerun setup. Keep TLS validation enabled. Never paste the connector token, application answers or résumé into a public issue or chat log.
